# Update Wise — Website

Multilingual marketing site for Update Wise (Astro, static output).
Locales: `es` (default, no URL prefix), `en`, `pt`, `zh`.

## Commands

```sh
npm install      # install dependencies
npm run dev      # dev server at localhost:4321
npm run build    # static build to dist/
npm run preview  # preview the production build
```

## Docs

Developer documentation lives in [`docs/`](docs/):

- `architecture.md` — structure, component tree, render flow
- `routing.md` — URL scheme, adding pages, 404
- `i18n.md` — locales, keys, adding a language
- `content.md` — `pages` collection, frontmatter
- `seo.md` — meta/hreflang/sitemap, pending TODOs
- `development.md` — scripts and conventions

Full Astro documentation: https://docs.astro.build
